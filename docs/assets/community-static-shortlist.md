# Community static asset shortlist

Checked **16 November 2026**, against game source at `f45e909`. This is a sourcing and integration queue, not an imported-asset manifest. No 3D model or texture archive was downloaded or added. Four public creator thumbnails were fetched to temporary storage for the visual observations below; no preview files are committed. The creator pages and public metadata below were inspected; actual archive contents, visual quality in Godot, source-file rights notices and performance remain to be checked during ingestion.

The goal is realistic tactical weapons, recognisable Stargate hardware and detailed industrial surfaces. Triangle count alone does not establish fidelity. The current Kenney assets are useful stylized substitutes; the file names `p90_smg.glb` and `mp5_silenced.glb` do not make their source models accurate P90/MP5 replicas. Their existing provenance must remain intact in [ATTRIBUTIONS.md](../../credits/ATTRIBUTIONS.md).

## Evidence and acquisition status

- **Sketchfab entries:** each linked model API returned `isDownloadable: true`; its `license.url` supplied the exact version, rather than inferring a version from the “CC Attribution” badge. These are free-download listings, but no account session or archive download was attempted. The official [Download API](https://sketchfab.com/developers/download-api) documents authenticated account access and service-provided glTF/GLB/USDZ downloads; the original upload format and the exact available archive contents are unverified for these candidates. Some ordinary model pages returned 403 to the research browser; their publicly accessible metadata is identified explicitly as the evidence instead. This does not establish that an authenticated download will succeed later.
- **Poly Haven entries:** the individual pages expose download formats, resolutions and direct map links without a login/payment step being presented. No file was fetched. Their [asset license page](https://polyhaven.com/license) identifies staff or directly contributing artists as the source and applies [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- **CC BY candidates:** the inspected metadata points to [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). At ingestion, preserve the asset title, creator, source, license, existing notices and a record of modifications. Add those to the repository attribution manifest and retain the downloaded license evidence. A fan creator's grant covers their contribution; it does not establish permissions for every underlying franchise right. The owner has already authorised consideration of creator-made CC0/CC BY Stargate fan models under the pipeline policy.
- **S / M / L:** S is a rigid cosmetic swap with existing gameplay anchors; M needs part separation, pivots, material adaptation or animation binding; L needs substantial rebuild/retopology or a new rig. These estimates are integration inferences, not creator guarantees.

## Recommended first insertion sequence

**Status, 16 November 2026 (AP-1c).** The M9 could not be acquired: Sketchfab's download endpoint answered HTTP 401 without an account session. Plastic Crate 02 was acquired, measured and integrated as the fallback proof ([record](../reviews/2026-11-16-ap1c-plastic-crate.md)). Its 1k glTF does not reference the opacity map; the vents are painted dark in the base colour, so it renders as a solid-looking crate. The sequence below is otherwise unchanged.

1. **M9 rigid visual pilot:** obtain the exact creator archive through the normal download path, preserve its license evidence, record a hash and measured bounds, and use the existing `WeaponModel`/`MuzzlePoint` wrapper. Verify the held first-person and third-person pose before adding reload articulation. This is a recommendation inferred from the described part structure and existing weapon loader, not a passed import result.
2. **P90, then M249:** use the same proof with their real shapes and PBR material sets; check the P90 magazine/optic and the M249 long muzzle. Keep the current fallback available until clean headless import, Forward+ screenshots and gameplay anchor checks pass.
3. **One Poly Haven prop and one small Metal Plate surface sample:** establish repeat scale, GL normals and material readability in a real mission without changing navigation, cover or authored room dimensions. Use the [shared authoring guide](../maps/ai-level-authoring.md) and live catalogue before choosing an attachment/module.
4. **SG-1 ring archive inspection:** this offers high visible value but carries more integration work. Treat the first delivery as a rigid cosmetic shell with the working gate lifecycle unchanged; only promise articulated chevrons/inner-ring motion after inspecting actual parts.
5. **DHD/staff sourcing improvement:** the cleared listings above are fallback leads. If their untextured/single-texture presentation falls short, keep looking for creator-made detailed assets instead of labelling these “hi-fi.” The generic iris is a mechanism study, not a drop-in milestone.

## Existing code contracts

The integration plan preserves these source-code contracts:

- `Stargate.tscn` has a cosmetic torus, seven `Chevrons` children and separate event-horizon/kawoosh/extraction nodes; `StargateRing.gd` currently coordinates **seven** locks. A nine-chevron art asset can be adapted, but a spinning inner-ring or nine-chevron gameplay binding is not already implemented.
- `DHDConsole.tscn` currently uses box meshes; the existing plan's blanket cylinder description is inaccurate. Its interaction area and `DHDDialer` references must survive a visual swap.
- No `iris_open_ratio` symbol was found in the inspected prop scripts. Inspect the actual `IrisServoHousing`/gate iris state before writing an animation adapter.
- [D-015](../DECISIONS.md#d-015--jaffa-armour-finish) attributes dark Jaffa metal to absent sky/reflection probes, not washout from intense ambient light. `WeaponBase._sanitize_glb_materials` currently forces imported weapon metallic terms to zero. Replacing realistic PBR assets should respect that current behavior or propose a separately measured lighting/material change.
- A format listing, creator's “game-ready” label, or `animationCount = 0` is not proof of Godot compatibility, useful pivots, absence of a skeleton or production fidelity. None of the candidate archives has yet passed the repository's import, scale, provenance and render checks.
