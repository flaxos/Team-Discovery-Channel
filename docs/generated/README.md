# Generated planning snapshots

The Alignment Engine writes `BOOTSTRAP_PROMPT.md`, `GDD.md`, `ROADMAP.md` and `TEAM_CONTRACT.md` here when an authenticated mutation or explicit export succeeds. These snapshots describe voting choices, not authoritative implementation or release status.

Root project documents, sprint history, reviews and development notes are maintained separately and are never overwritten by voting or export. Review generated changes before committing them. API Git operations are disabled by default; when explicitly enabled they require a separate export token and a feature branch, commit only the four generated files, and push only when explicitly requested.
