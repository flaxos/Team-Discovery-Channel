## 🛠️ Alignment & Voting Web App
To run the live voting and prompt compiler app:

```bash
cd alignment-app
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to cast votes, propose custom mechanics, or regenerate the bootstrap prompts!
