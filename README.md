# Team Discovery Channel

Team Discovery Channel is a collaborative Godot project building a co-op Stargate tactical extraction shooter. The repository combines the playable Godot client, a browser-based alignment/voting tool for grounded design decisions, and the current engineering notes and validation records used during hardening and integration work.

## Current project status

The game is in a stabilized vertical-slice state with:

- a Godot 4.4.1 client in `client/`
- ENet multiplayer lobby and mission setup using `NetworkManager.gd`
- host-selected mission and difficulty flow for SGC Defense and SGC UAT modes
- map access and gate lifecycle cleanup work tracked under `plan/`
- hardening reports under `docs/hardening/`
- a React + Express planning app in `alignment-app/` for voting and generated planning documents

This repo is not only a concept prototype anymore: it includes test infrastructure, CI workflow definitions, and documented operating procedures for validation and release checks.

## Getting started

### Requirements

- Godot 4.4.1
- Node.js 22.12+ (project workflow uses 22.14 in CI)
- Python 3.11+ for validation tooling
- npm

### Alignment app

```bash
cd alignment-app
npm install
npm run dev
```

Then open http://localhost:5173 and sign in with the API token generated by:

```bash
cd alignment-app
npm run auth-token
```

The API defaults to localhost-only access. For remote or tunnel usage, set `ALIGNMENT_HOST` and `ALIGNMENT_ALLOWED_ORIGINS` explicitly and use the access token in the browser session.

### Godot game

Launch the project from the repo root:

```bash
godot --path client
```

For a quick headless smoke check:

```bash
godot --headless --path client --quit
```

Important run flags supported by the runtime include:

```bash
godot --headless --path client -- --server --port 7777
# or
 godot --headless --path client -- --connect 127.0.0.1 --port 7777
```

### Validation

Run the full Godot validation profile:

```bash
python3 tools/run_godot_tests.py --profile full --timeout 30
```

Run the runner contract tests:

```bash
python3 -m unittest discover -s tools/tests -v
```

Run the alignment API tests and frontend build:

```bash
cd alignment-app
npm ci --no-audit --no-fund
node --test server/*.test.js
npm run build
```

## Grounding and project discipline

The project intentionally separates maintained design docs from generated output:

- root docs such as `README.md`, `GDD.md`, `ROADMAP.md`, and `TEAM_CONTRACT.md` are treated as maintained project documentation
- generated outputs under `docs/generated/` are created by the Alignment Engine and reviewed before commit
- design changes are expected to be checked against the current gameplay, test runner, and CI requirements before release assumptions are made
